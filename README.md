# Sink a Startup

A Battleship-style Java game where the player tries to sink
three computer-controlled startups on a 7x7 grid.

## Goal

Sink all three startups using the fewest guesses possible.

## How to Play

The computer places three startups on a virtual 7x7 grid.

The player enters guesses such as:

A3
C5

The game responds with:

- Hit
- Miss
- You sunk [Startup]

When all three startups are sunk, the game ends and displays
the player's rating.
